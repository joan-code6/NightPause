Night Pause

Privacy policy

Last updated: 27 September 2026

Night Pause helps pause active media on an Android phone after a connected Wear OS watch reports that the user has fallen asleep.

Information used

Night Pause uses the watch’s sleep or awake state and the time of that state change. The watch sends this information to the paired phone through the Wear OS Data Layer so the phone can schedule or cancel a pause. The phone checks whether an Android media session is playing and sends it a pause command. Night Pause does not read or store the media title, podcast name, listening history, audio, or account credentials.

The app stores its enable setting, pause delay, and event-processing state on the phone or watch. This information is used only to operate Night Pause.

Sharing and storage

Night Pause does not send this information to the developer or to a Night Pause server, and does not use advertising or analytics. Sleep state is transmitted only between the paired watch and phone for the app’s core function. App preferences and event-processing state remain on those devices. Uninstalling the apps removes their local app data.

Permissions

The watch requests Activity Recognition access so it can receive sleep-state updates from Wear OS Health Services. The phone requires notification access so Android allows Night Pause to control active media sessions. Users can revoke either permission in system settings; the related feature then stops working.
